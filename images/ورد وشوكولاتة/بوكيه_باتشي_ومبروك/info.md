# معلومات المنتج: بوكيه جوري وبابونج يتوسطه شوكولاتة باتشي

## التصنيف المقترح
ورد وشوكولاتة

## وصف المنتج التفصيلي
- **النوع**: باقة / بوكيه مع شوكولاتة.
- **التصميم والتغليف**: الباقة مغلفة بورق بيج فاتح بخطوط بنية في أطرافه. وتتوسط الورود **علبة شوكولاتة باتشي (Patchi)** بيضاء مربعة مربوطة بشريطة. يوجد كرت تهنئة مكتوب عليه "Congratulations I'm so proud of you".
- **المكونات والورود**: زهور جوري حمراء داكنة، وزهور البابونج/الكاموميل (أبيض وأصفر) موزعة بشكل جميل حول علبة الشوكولاتة.
